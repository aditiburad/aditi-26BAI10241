# Library Management System
<br>

<h2>OVERVIEW</h2>
<br>
The Library Management System is a Python application that manages library operations like book records, member records, issuing books, and returns. It uses SQLite as the backend database and offers a simple menu-driven CLI interface.
<br>

---

<h2>💡 Features</h2>

 ✔ Book Management  
- Add new books  
- View all books  
- Update book details  
- Delete books  
- Search books  

 ✔ Member Management  
- Add members  
- View member list  
- Update member information  
- Delete members  

✔ Issue & Return System  
- Issue books to students  
- Check availability  
- Record return date  
- Fine calculation (optional)

✔ Database  
- SQLite database (`library.db`)  
- Auto table creation  
- Secure and optimized queries

---

---

<h2>🛠 Technologies Used</h2> 

- **Python 3**
- **SQLite3**
- **OS module**
- **Datetime library**

---

<h2>🚀 How to Run</h2>

 Step 1: Clone this repository  
 Step 2: Navigate to the folder  
Step 3: Run the main program  
The database will be created automatically on first run.
